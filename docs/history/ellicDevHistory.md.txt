# Ellic Development History

This document describes the historical development of the Ellic locomotion platform.

The project has gone through many prototype generations exploring different mechanical solutions, drive systems, and ergonomics.

The table below lists the major development stages.

---

## Prototype Evolution

| # | Prototype | Cost (k RUB) | Description |
|---|-----------|---------------|-------------|
|1|Scissors|200|First experimental prototype|
|2|Combine|600|Developed with Bauman Moscow State Technical University. No drive system yet|
|3|Ladya|750|New kinematic approach. Belt-linked pulley system introduced|
|4|Scooter|700|Return to lever drive concept|

|6|Motor Control System v1|570|Development of motor controllers, PCBs, firmware, gyroscope control|
|7|Lebed|870|Frame stiffness improvements|
|8|Kareta|650|Frame geometry experiments for stability|
|9|Mini Kareta|550|Frame optimization for transport|

|12|Orange Goose|900|Three-motor configuration experiments|

|14|Black Raptor|960|Simplified frame and cantilever wheel mounting|
|15|Motor Raptor|570|Compact motorized version|
